# Faddernavn

A voting board for SIFI faddere. Add people, suggest names, and vote once per name.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Commands

- `npm run build` checks the production build.
- `npm test` runs the project test.
- `npm run db:generate` creates a migration after a database schema change.
